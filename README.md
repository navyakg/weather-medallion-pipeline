I designed and built an end-to-end Medallion Architecture pipeline using PySpark and Python. The Bronze layer ingests raw JSON payloads from REST APIs. In the Silver layer, I enforced explicit schemas, flattened nested JSON structs, and partitioned output files by dimensional keys in Parquet format. Finally, the Gold layer computes aggregated business KPIs like rolling averages and extremes, producing optimized datasets ready for BI reporting.
